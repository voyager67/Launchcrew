# Roadmap

The first release aims to be useful on day one without pretending every workflow is universally optimal. Priorities below should change in response to real maintainer and user feedback.

## v0.1 — Portable foundation

- [x] Core spec-driven engineering skills.
- [x] Product, research, security, performance, accessibility, AI-evaluation, incident, release, growth, and startup operations workflows.
- [x] Codex-specific agent definitions and safe installation paths.
- [x] ChatGPT skill ZIP packaging and Projects fallback guide.
- [x] Automated metadata/config validation and CI.

## Next

- Gather real examples of successful and failed workflows, with permission and sensitive details removed.
- Add focused tests for edge cases in package generation and installation.
- Add domain packs only when there is a clear audience and measurable workflow improvement.
- Consider optional machine-readable evaluation scenarios and output schemas for high-frequency skills.
- Improve compatibility checks when Codex or ChatGPT's skill-import behavior changes.

## Non-goals

- Replacing the user's judgment or repository policy.
- Promising autonomous production deployments.
- Adding dozens of near-duplicate skills for vanity counts.
- Making unverified claims about speedups, accuracy, or adoption.
