# Roadmap

LaunchCrew aims to be useful on day one without pretending every workflow is universally optimal. Priorities should change in response to reproducible user feedback and maintainer capacity.

## v0.1 — Portable foundation

- [x] 23 reusable workflow skills covering specification, delivery, product discovery, research, quality, AI evaluation, operations, and release.
- [x] Ten project-scoped Codex specialist profiles.
- [x] Safe project-local and global skill installation with collision refusal.
- [x] Individual ChatGPT skill ZIP packaging and a Projects fallback guide.
- [x] Repository validation, unit tests, CI, contribution forms, and release documentation.

## Next priorities

1. Collect reproducible Codex and ChatGPT compatibility reports across product versions and workspaces.
2. Expand installer and packaging regression coverage, especially path edge cases and partial-failure behavior.
3. Add focused workflow demonstrations with sample inputs, expected artifacts, and clear verification evidence.
4. Improve skill-specific evaluation scenarios where a reliable pass/fail signal can be defined.
5. Add domain packs only when there is a clear audience and measurable workflow improvement.
6. Revisit product instructions when official Codex, ChatGPT Skills, or Agent Skills behavior changes.

## Non-goals

- Replacing the user's judgment, project instructions, or repository policy.
- Promising autonomous production deployments.
- Claiming that ChatGPT Skills or Codex features are enabled for every account or workspace.
- Adding near-duplicate skills to inflate the skill count.
- Publishing unverified speed, accuracy, benchmark, adoption, or customer-impact claims.
