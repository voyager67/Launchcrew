# Example: invitation-based sign-up

This example demonstrates the shape of a spec; it is illustrative, not an implementation or a security guarantee. Adapt requirements to the real repository and identity provider.

Files:
- `requirements.md`: observable outcomes and non-goals.
- `design.md`: a sample architecture and trust boundaries.
- `plan.md`: small slices with dependencies.
- `acceptance.md`: positive and negative scenarios.
