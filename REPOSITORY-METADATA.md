## Short pitch

LaunchCrew turns loosely structured AI coding sessions into a repeatable engineering workflow: clarify the problem, define testable requirements, delegate independent investigation, implement small slices, and review actual test evidence before shipping.

It is a workflow kit—not an autonomous runtime, a hosted agent service, or a guarantee of product-specific tool access.
