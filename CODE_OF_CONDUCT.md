# Contributor Covenant Code of Conduct

## Our pledge

We are committed to making participation in this project a respectful, constructive, and harassment-free experience for everyone.

## Expected behavior

- Be considerate, professional, and specific.
- Welcome good-faith questions and differing technical opinions.
- Critique ideas and implementations, not people.
- Share only material you are allowed to disclose.
- Give maintainers and contributors room to learn and correct mistakes.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sustained personal attacks, deliberate disruption, and publishing private information without consent are not acceptable.

## Enforcement

Report conduct that violates this policy through a private channel available on the repository owner's GitHub profile. Do not post private information in a public issue. Maintainers should respond proportionately, prioritize safety, and document decisions without exposing personal details.

This code of conduct is adapted from the Contributor Covenant, version 2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct.html
